# Милана Алехина — сайт психолога и детского нейропсихолога

## Открыть сайт

Полностью распакуйте архив и откройте `index.html` в Chrome, Edge, Firefox или Safari. Установка npm и сборка не нужны. Для публикации загрузите index.html, styles.css, script.js и всю папку assets в корень статического хостинга, например GitHub Pages.

При желании локальный сервер запускается командой `python -m http.server 8000` из папки сайта; адрес — http://localhost:8000.

## Возможности и файлы

- index.html — все тексты, цены и контакты, FAQ и окна услуг.
- styles.css — цвета, шрифты, композиция и адаптивные стили.
- script.js — меню, диалоги, появление разделов, индикатор прокрутки и выключатель анимации.
- assets/portrait-original.png — исходная фотография пользователя без обработки.
- Нажатие на фотографию открывает увеличенный просмотр; закрытие — кнопкой, Escape или нажатием на фон.
- assets/landscape.webp — акварельный фон из предыдущей версии, созданный встроенным генератором изображений.
- assets/serif.woff, serif-italic.woff, sans.woff — локальные шрифты Cormorant Garamond и Onest. Лицензии SIL OFL приложены.

Фон медленно движется средствами CSS; декоративная рябь также сделана на CSS. Это не видеозапись воды. Появление разделов происходит при прокрутке. Переключатель движения учитывает prefers-reduced-motion; диалоги закрываются кнопкой, Escape или нажатием вне окна. На телефоне цены видны под названием услуги.

## Адаптивность для разных экранов

- Телефоны от 280–320 px по ширине: масштабируемые заголовки, короткие подписи, кнопки и цены без горизонтальной прокрутки; учтены безопасные отступы для экранов с вырезами. Переключатель анимации на узких телефонах занимает меньше места.
- Смартфоны в альбомной ориентации и планшеты шириной 701–960 px: раскрывающееся меню вместо тесной горизонтальной навигации; вертикальная прокрутка внутри меню на низких экранах. В портретной ориентации планшета фотография и текст раздела «Обо мне» расположены друг под другом.
- Ноутбуки и десктопы: сохранена исходная композиция, ограниченная ширина основного контента и удобные отступы.
- Широкие экраны от 2100 px, включая 4K-телевизоры: увеличены заголовки, основной текст, ссылки, меню и интерактивные элементы; страницы не растягиваются на всю ширину без ограничений.
- На устройствах с сенсорным управлением выключен scroll-snap и движения при hover, для снижения нагрузки отключена фоновая анимация. На устройствах с запросом уменьшения движения (prefers-reduced-motion) анимации также отключены.
- Вёрстка использует viewport-fit=cover, safe-area-inset, svh/dvh и адаптивное масштабирование. Без фреймворков, внешних CSS и серверных зависимостей. Фотография не перегенерирована, изображения сохранены из предыдущей версии.

В Chromium просмотрены скриншоты главной страницы с локальными шрифтами и фоном, а также фотографии на телефоне и планшете. ## Фотография

assets/portrait-original.png — исходный файл 1536×2048, сохранён побайтово без изменений. Он открывается при нажатии на фото.

Для небольшого блока используются отдельные PNG assets/portrait-display-*.png: предварительная низкочастотная фильтрация и уменьшение BICUBIC без повышения резкости, дизеринга и потерь при сохранении. Это обычное сглаживание при уменьшении, без ИИ и перерисовки лица. Его цель — сделать мелкую контрастную фактуру менее резкой; маленькая версия будет немного мягче исходника.

Браузер выбирает размер через srcset с учётом размера блока и плотности экрана. ResizeObserver уточняет фактическую ширину. Из отображения фотографии исключено дополнительное кадрирование object-fit:cover и трансформация появления: изображение показывается в исходных пропорциях.

Версии подготовлены скриптом tools/prepare_portrait.py (для повторного запуска нужны Python и Pillow; для работы самого сайта они не нужны).

В Chrome проверены загрузка адаптивной версии в блоке, выбор portrait-display-480.png при ширине около 402 CSS px и DPR 1, а также открытие исходника 1536×2048 в увеличенном просмотре. Побайтовое совпадение оригинала с загруженным файлом проверено внутри ZIP.

Маленькие пронумерованные подписи 01–04 над заголовками разделов удалены.
